# 건강기능식품 표시·광고 기준 요약 (카피 작성용)

> 근거: 「식품 등의 표시·광고에 관한 법률」(식품표시광고법) 제8조(부당한 표시·광고 금지), 제10조(자율심의), 「건강기능식품의 표시기준」, 「전자상거래 등에서의 상품 등의 정보제공에 관한 고시」.
> 이 문서는 작성 가이드다. 법령과 심의 기준은 바뀔 수 있으므로 **게재 전 한국건강기능식품협회 자율심의로 최종 확인**한다.

## 1. 기능성 표현: 인정받은 문구를 그대로 쓴다

| 구분 | 예시 | 원칙 |
|---|---|---|
| 고시형 원료 기능성 | EPA 및 DHA 함유 유지: "혈중 중성지질 개선·혈행 개선에 도움을 줄 수 있음" | 식약처 고시 문구를 글자 그대로 쓴다 |
| 개별인정형 원료 | 인정서에 적힌 문구 | 인정서 원문 그대로 쓴다. 인정번호와 원료명을 함께 쓴다 |
| 영양소 기능 | 비타민E: "유해산소로부터 세포를 보호하는데 필요" | 영양소 기능 문구 그대로 쓴다 |

- 문구를 줄이거나 바꾸거나 합치지 않는다. "~에 좋은", "~을 개선하는" 같은 식으로 바꿔 쓰면 안 된다.
- 헤드카피는 기능성의 **주제어**(예: "혈행 건강")까지만 쓴다. 효과를 단정하는 문장("혈관이 깨끗해집니다")은 쓰지 않는다.
- 기능성과 함께 인정 조건(1일 섭취량)을 표기한다.
- 표기: "식약처 인정" (O) / "식약처 인증·승인·허가" (X)

## 2. 금지 표현 (lint: 수정 필수)

| 유형 | 예 | 대안 |
|---|---|---|
| 질병 예방·치료 | 치료, 완치, 예방, ○○병에 효과 | 인정 기능성 문구만 사용 |
| 의약품 오인 | 특효, 약효, 처방, 복용, 투여 | "섭취", "섭취량" |
| 질병명 직접 언급 | 당뇨, 고혈압, 관절염, 항암 | 인정 문구 범위의 주제어만 |
| 부작용 부정·안전 보장 | 부작용 없음, 100% 안전 | 삭제 |
| 인증 오표기 | 식약처 인증/승인, FDA 승인 | 식약처 인정 |
| 해독·디톡스 | 디톡스, 독소 배출 | 삭제 |
| 다이어트 과장 | 살 빠지는, 식욕 억제, 지방 태우는 | 인정 문구(예: 체지방 감소에 도움을 줄 수 있음) |
| 즉각 효과 | 즉효, 하루 만에 | 삭제 |

## 3. 주의 표현 (lint: 확인 필요 — 근거가 있거나 심의 통과 시에만)

- **최상급·배타 표현**: 최고, 최초, 유일, 1위, No.1 → 객관적 근거(조사기관, 기간, 기준)를 함께 쓴다
- **체험기·후기**: 기능성을 체험기로 보여주는 광고는 금지. 후기 섹션은 배송·맛·편의성 위주로만 쓰고 심의를 받는다
- **전문가 추천**: 의사·약사·한의사 등의 추천·보증은 쓰지 않는다
- **효과/효능**: "도움을 줄 수 있음"으로 완화한다
- **시험·논문 인용**: 출처를 표기한다. 원료 연구를 제품 효과처럼 보이게 쓰지 않는다
- **천연·무첨가·특허**: 증빙(인증서, 특허번호)이 있을 때만 쓴다
- **비교 광고**: 객관적 근거 없이 타사를 비교·비방하지 않는다. 비교표는 "당사 기준 예시"임을 밝힌다

## 4. 이미지 주의
- 병원, 의사 가운, 청진기, 주사, 알약 처방 장면처럼 **의약품이나 의료를 연상시키는 비주얼**을 쓰지 않는다
- 비포/애프터 신체 비교, 체중계 수치 강조를 쓰지 않는다
- 장기(심장, 혈관, 간) 일러스트로 효과를 **시각화**하는 것은 심의에서 문제가 될 수 있다. 쓰려면 심의 전에 확인한다

## 5. 필수 표기 (페이지 하단 `info` + `caution` 섹션)

상품정보제공고시(건강기능식품) 기준 항목:
1. 제품명
2. 식품의 유형 (건강기능식품)
3. 제조업소 명칭 및 소재지 (수입품: 수입업소, 제조국)
4. 제조연월일, 소비기한
5. 포장단위별 내용량
6. 원료명 및 함량
7. 영양·기능정보
8. 섭취량, 섭취방법, 섭취 시 주의사항, 부작용 발생 가능성
9. "질병의 예방 및 치료를 위한 의약품이 아님"을 알리는 문구 → 렌더러가 caution 섹션에 **자동 삽입**
10. 유전자변형 건강기능식품 여부
11. 수입식품 여부 ("수입식품안전관리특별법에 따른 수입신고를 필함" 등)
12. 소비자상담 관련 전화번호

추가:
- 표시·광고 **심의필** 번호 (`caution.reviewNumber`)
- 알레르기 유발 물질 (해당 시)
- GMP 표기는 실제 인증을 받은 경우에만

## 6. 자동 점검의 한계
`scripts/lint.mjs`는 키워드 기반 1차 필터다. 맥락상 문제가 되는 표현(은유, 이미지 속 텍스트, 암시)은 잡지 못한다. 기획안 단계에서 이 문서를 기준으로 직접 검토한다.
