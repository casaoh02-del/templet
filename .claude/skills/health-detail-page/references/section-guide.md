# 섹션 구성 가이드

## 기본 흐름 (건강기능식품)

구매 심리 흐름: **주목 → 공감 → 해결 → 신뢰 → 행동**. 신뢰 구간(기능성, 원료, 품질)이 다른 카테고리보다 길다.

| # | 섹션 타입 | 목적 | 필수 |
|---|---|---|---|
| 1 | `hero` | 3초 안에 "무엇을 위한 제품인가" 전달. 기능성 주제어 + 제품컷 + 신뢰 배지 | ✅ |
| 2 | `pain` | 타깃이 겪는 일상 상황 공감 (질병·증상이 아니라 **생활 습관**) | |
| 3 | `solution` | 제품/원료가 답이라는 연결 | |
| 4 | `function` | **식약처 인정 기능성** 원문 표기 | ✅ |
| 5 | `ingredient` | 원료 스토리, 함량, 형태(rTG, 식물성 캡슐 등) | ✅ |
| 6 | `numbers` | 핵심 수치 3개 (함량, 섭취 편의, 구성) | |
| 7 | `compare` | 차별점 비교 (근거 있는 항목만) | |
| 8 | `quality` | GMP, 시험성적, 원산지, 포장 방식 | ✅ |
| 9 | `howto` | 섭취 방법, 보관 방법 | ✅ |
| 10 | `target` | 추천 대상 (생활 상황 기준) | |
| 11 | `faq` | 구매 망설임 해소 (섭취 시간, 맛·냄새, 병용) | |
| 12 | `cta` | 마무리 한 줄 + 라이프스타일컷 | |
| 13 | `info` | 상품정보제공고시 표 | ✅ |
| 14 | `caution` | 섭취 시 주의사항 + 의약품 아님 문구 + 심의필 번호 | ✅ |

필요 없는 섹션은 빼고, 같은 타입을 여러 번 써도 된다. 디자이너가 따로 만든 이미지는 `image` 타입으로 원하는 위치에 넣는다.

## 카피 원칙

- **헤드카피**: 2줄, 줄당 8~14자. 기능성 주제어나 타깃 상황을 담고 `**강조**`는 한 곳만 쓴다.
- **서브카피**: 2줄 이내. 헤드카피를 구체화한다(함량, 형태, 섭취 편의).
- **아이브로우**: 영문 대문자 라벨(`INGREDIENT`) 또는 짧은 한글 라벨.
- 문장은 "~합니다", "~하세요" 체로 통일한다. 느낌표는 쓰지 않는다.
- 숫자는 1일 섭취량 기준으로 쓰고, 기준은 주석(`note`)에 밝힌다.

## 섹션별 팁

- **hero**: 배지는 3개 이하로, 사실만 쓴다(식약처 인정 기능성, GMP, 원료 형태). 제품컷은 누끼 + 연한 배경.
- **pain**: "혈관이 막혀" 같은 증상이 아니라 "기름진 외식이 잦은 분"처럼 생활 습관으로 쓴다.
- **function**: 기능성이 여러 개면 카드 여러 장으로 나눈다. `note`에 "식품의약품안전처에서 인정한 기능성 원료의 기능성 내용"이라고 밝힌다.
- **ingredient**: 원산지, 원료사, 형태, 함량을 쓴다. 원료 연구를 인용할 때는 출처를 쓰고 제품 효과처럼 쓰지 않는다.
- **compare**: 항목은 형태, 함량, 캡슐 크기, 섭취량처럼 **검증 가능한 사양**으로만 구성한다.
- **quality**: 증빙이 있는 것만 쓴다(시험성적서, GMP 지정서).
- **faq**: 답변에서 효과를 약속하지 않는다.

## 레이아웃 사양
- 폭 860px(스마트스토어 기준). 쿠팡처럼 780px 채널은 `meta.width: 780`으로 바꾼다.
- 섹션 좌우 여백 64px, 상하 120px. 법정 표기 섹션은 80px.
- 톤: `light`(흰), `soft`(연한 브랜드 톤), `primary`(브랜드 컬러), `dark`. 섹션마다 `tone`으로 바꿀 수 있다. 같은 톤이 3개 이상 연속되지 않게 한다.
